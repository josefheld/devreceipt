# DevReceipt · Delivery receipts for client development work

Show your client what was delivered, not how many hours were logged.

DevReceipt reads the Git history and the time records of a period and turns them into
a short Client Delivery Brief: the outcomes the client got, why they matter, how the
recorded effort compares with the original estimate where that comparison is fair,
and what is still open. Every statement rests on an Evidence Ledger the client can open.

## Status

Private beta, dogfooded on a real client project. First focus: macOS, Git repositories,
Claude Code for the writing.

Request access: https://kigazon.com/devreceipt.html

## What DevReceipt is not

- Not a timesheet and not a productivity score. No hours derived from commits or agent runtime.
- Not a billing or invoicing tool.
- Not a cloud service. Repositories and time records stay on your machine.
